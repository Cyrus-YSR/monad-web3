# 实现用户分享图片应用

## 1. 智能合约设计

### 1.1 NFT 账号合约 (AccountNFT.sol)
- 实现 ERC721 标准
- 可配置的铸造费用
- 铸造功能，需要支付 ETH
- 检查用户是否拥有 NFT 的功能

### 1.2 图片分享合约 (ImageShare.sol)
- 存储图片哈希和文字内容
- 点赞功能，每个用户每个图片只能点赞一次
- 获取图片列表和详情的功能

## 2. 前端实现

### 2.1 页面设计
- **首页**：展示图片列表，包含点赞功能
- **铸造页面**：用于铸造 NFT 账号
- **分享页面**：用于上传图片和文字

### 2.2 组件设计
- **ImageCard**：展示图片、文字和点赞按钮
- **MintNFT**：NFT 铸造表单
- **ImageUpload**：图片上传组件

### 2.3 功能实现
- 钱包连接和身份验证
- NFT 铸造和余额检查
- 图片上传和分享
- 点赞功能（单次限制）

## 3. 实现步骤

### 3.1 智能合约开发
1. 编写 AccountNFT.sol 合约
2. 编写 ImageShare.sol 合约
3. 配置 Hardhat 部署脚本

### 3.2 前端开发
1. 更新配置文件，添加新合约信息
2. 实现铸造页面和组件
3. 实现分享页面和组件
4. 实现首页和图片展示
5. 添加点赞功能

### 3.3 测试和部署
1. 本地测试合约功能
2. 部署到本地 Hardhat 节点
3. 测试前端功能

## 4. 技术栈

- **智能合约**：Solidity 0.8.28
- **前端框架**：Next.js 14 + React 18
- **Web3 库**：Wagmi 2.9 + Viem 2.9
- **UI 组件**：Tailwind CSS + RainbowKit

## 5. 项目结构

```
contracts/
├── AccountNFT.sol       # NFT 账号合约
└── ImageShare.sol       # 图片分享合约

frontend/src/app/
├── mint/               # NFT 铸造页面
├── share/              # 图片分享页面
├── components/
│   ├── ImageCard.tsx   # 图片卡片组件
│   ├── MintNFT.tsx     # NFT 铸造组件
│   └── ImageUpload.tsx # 图片上传组件
└── lib/
    └── new_config.ts   # 新合约配置
```
